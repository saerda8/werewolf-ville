# NPC 白天交谈 / 晨会 / 死亡态问题梳理

更新时间：2026-06-09

这份文档只记录用户当前明确指出的问题，不讨论实现方案。

## 1. 白天真实谈话卡住后，底层思考还在跑

用户指出的关键不是“气泡没显示”，而是：

- NPC 跟警长进入真实谈话后，如果第二条模型线迟迟不返回，前端只是把蓝色思考/计划气泡藏起来了。
- 但日志里还能看到它继续在思考、计划，说明底层链路并没有真的停住。
- 用户希望的行为是：一旦进入正式谈话，就必须真正压住后续思考/计划/行动；模型空回时要重试，直到真的返回白色谈话气泡并完成后才算释放。

## 2. 黄昏讨论里，NPC 发言太和气

用户反复强调：

- 讨论时有人怀疑另一个人，被怀疑的人应该解释、反踩、辩护。
- 现在很多发言像客套话，缺少狼人杀那种互相指认、互相辩护的攻击性。
- 这不是投票环节的问题，而是黄昏讨论阶段的发言质量问题。

## 3. 黄昏讨论 UI 位置偏右

用户希望黄昏讨论的 UI 再往左一点。

## 4. 第二天白天集合流程有三个问题

用户看到的现象是：

- NPC 到广场时，镜头没有稳定对准广场 / 死者位置。
- NPC 到场后有些背对玩家或侧对玩家，没有统一正面朝向。
- 到了广场以后，头顶还挂着“参加早晨讨论...”之类的气泡，像是还在执行普通行动，体验上不对。

用户要的是：

- 晨会是特殊阶段，不要继续沿用普通行动气泡。
- 到广场以后必须正面朝玩家。
- 镜头要自动落到讨论中心。

## 5. 被投死的人没有真正退出世界

用户举的例子是山姆：

- 他第一天黄昏被投死，应该已经进入死亡 / 牢房等价态。
- 但第二天他又自己走出去，甚至回酒吧工作。

用户要的是：

- 被投死的人在玩法上就当作死了。
- 视觉上应当是灰掉的尸体，躺在牢房里，不再行动，不再拥有智能。
- 不能只是“被关着”，但还继续参加后续生活。

## 6. 牢房位置和尸体落点不对

用户希望：

- 被投死的人进入克罗家右边的两个牢房。
- 进入后是尸体状态，躺在里面。
- 不能跑到克罗家内部，也不能站在墙上。
- 不能穿墙走过去。

## 7. 第二天任务里，五金店道具被错误绑定成店主存活条件

用户明确说：

- 制造子弹的工具，和店主亚瑟是否死亡没有直接关系。
- 现在的文本或条件把“亚瑟死亡或不存在”当成了拿工具失败的原因，这是错的。

这说明任务交互的依赖条件写歪了。

## 8. 第二天任务文案必须固定

用户要求正式文案保持为：

`通过深挖女性角色获得银质项链/去五金店找到制造子弹的工具(二选一)`

这句不能改。

## 9. 第三天早晨晨会卡死

用户指出：

- 第二天晚上结束后，第 3 天早上晨会时，所有 NPC 都不去广场，包括警长。
- 游戏直接卡住。

这更像是晨会阶段推进断了，而不是单个 NPC 的移动小问题。

## 10. 这批问题的共性怀疑

目前能看出来的共性，不是单一 UI 偏差，而是几条状态线混在一起：

- 真实谈话、普通思考、行动中气泡没有完全隔离。
- 晨会 / 黄昏 / 死亡 / 牢房 这些特殊阶段，没有把旧状态彻底收干净。
- 被投死的人、晨会参与者、任务道具的可用条件，可能还在沿用旧的“活人 NPC”逻辑。

这份文档先保留用户原意，后续如果要进入开发，再把每条问题拆成对应的修复项和验证项。

## 2026-06-09 修复记录

- 真实谈话锁：旧行动决策线程在 LLM 返回后、写日志/状态/待执行行动前再次校验 generation 和真实谈话锁；被警长谈话打断后不再把旧思考、计划、开始行动写进日志或状态。
- 晨会：Day2/Day3 早晨集合不再写“前往广场参加早晨讨论”普通行动文本；等待到场超过 15 秒会兜底落位，避免晨会卡死；前端在晨会阶段隐藏蓝色普通行动泡、镜头平移到广场、NPC 静止正面。
- 关押/死亡态：被投出者进入牢房时清理旧计划、旧对话、旧路径；押送完成后以 `jailed_corpse` 状态显示为灰色躺地尸体，不再暴露普通行动/思考状态；夜晚切换会强制留在牢房。
- 五金店工具：制造子弹工具改为货架道具，不再依赖亚瑟是否存活、是否狼人或是否被拘留；成功日志和接口消息为“恭喜你获得制作子弹的工具”。
- 任务文案：银器资源任务 label/description 固定为 `通过深挖女性角色获得银质项链/去五金店找到制造子弹的工具(二选一)`。
- 黄昏讨论：发言 prompt 纳入前面发言；如果有人点名怀疑自己，后发言者必须正面解释并反驳/反踩，避免被踩后无回应。
