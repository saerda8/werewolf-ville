# 开局流程与右侧 UI 细化审计计划

日期：2026-06-02

本文档按用户在本轮对话中多次描述的长文本需求还原规则，并对照当前实现列出差距。它不是最终 PRD，而是下一轮实现前的验收基准。

## 1. 需求还原

### 1.1 游戏开局必须发生的事情

1. 点击开始游戏后，本局随机选择 2 个狼人。
2. 狼人知道彼此身份，并能互相掩护；普通 NPC 不知道谁是狼人，也不知道其他隐藏身份。
3. 场景中已有一具前置尸体，尸体来自非活动 NPC 模型，躺倒、变灰。
4. 早晨不是固定晨会，而是“先发现尸体，再围绕尸体组织讨论”。
5. 所有存活 NPC 与警长 Crow 聚集在尸体附近，不应站在房屋内或墙上。
6. 镜头开局应对准聚集圈中心，玩家一开始能看到人群和尸体。

### 1.2 警长 Crow 的开场发言

Crow 开局发言不是一句短说明，而应分多段气泡展示故事背景：

1. 说明自己身份：“我是这个小镇的警长”。
2. 说明昨夜命案：谁遇害了，尸体在哪里。
3. 说明初步观察：尸体疑似有野兽抓痕/撕咬痕迹，但死因仍需调查。
4. 说明玩家目标：今天会逐一找大家问话。
5. 说明线索 UI：如果 NPC 有线索，右侧列表灯泡会亮，玩家可以去找他。
6. 询问所有人：“昨天晚上大家都在做什么？”
7. 第一轮 NPC 发言结束后，Crow 还要再说一段收束话：
   - “好吧，你们先去做自己的事。”
   - “我会在黄昏时再召集大家讨论。”

### 1.3 开局讨论的两轮结构

第一轮：

1. Crow 先发言，发言由固定剧情文本驱动，不等待 LLM。
2. 每个 NPC 依次由模型生成简短发言。
3. 发言内容应包括昨晚行踪、看到/听到的异常、对命案的反应。
4. 语气必须严肃紧张，不应开心、轻松或开玩笑。
5. 第一轮 NPC 只能发言，不能离开、不能行动。

第二轮：

1. 第一轮所有 NPC 发言结束后，Crow 先宣布解散和黄昏再集合。
2. 然后每个 NPC 由模型生成离开理由和接下来要做的事。
3. 不能是固定句式“我要去某地”，要自然说明为什么离开。
4. 离开目的地必须符合职业与场景，例如：
   - 五金店老板去五金店。
   - 咖啡店老板去咖啡店。
   - 学生/图书管理员去学院或图书馆。
   - 酒馆相关角色去酒馆。
5. 目的地不能只停在地标中心点，必须指向可到达的具体物件或物件前方，例如书架、柜台、货架、花园。
6. 发言完成后 NPC 才开始移动。
7. 所有 NPC 都必须最终离开聚集圈，不能最后几个人卡在原地。

### 1.4 白天探索与交谈任务

1. Day 1 的警长任务是和另外 7 个 NPC 都进行一次普通交谈。
2. 任务计数显示为 `0/7`、`1/7` 等。
3. NPC 自主生活是优先目标，次要目标是发现线索、辅助警长或自行调查。
4. NPC 如果发现新线索或有重要想法，右侧列表灯泡亮起。
5. 警长点击 NPC 的交谈按钮后，Crow 自动走到 NPC 身边。
6. 走到身边后，NPC 先主动说当前想告诉警长的话，不应要求警长先输入。
7. 每个 NPC 每天只能普通交谈一次。

### 1.5 深度挖掘

1. 深度挖掘总次数为 3 次，不随天数重置。
2. 正常情况下，NPC 卡片只显示“交谈”按钮。
3. 对某个 NPC 完成普通交谈后，该 NPC 卡片上的“交谈”隐藏或禁用。
4. 只有在该 NPC 已经普通交谈过，且警长仍有深挖次数时，才显示“深入挖掘”按钮。
5. 点击深入挖掘时弹出较大的输入框，让玩家先输入要问 NPC 的话。
6. Crow 到 NPC 身边后先说玩家输入的话，NPC 再根据该话回复。
7. 右侧 UI 需要显示剩余深挖次数。

### 1.6 黄昏讨论与投票

1. 右侧不应存在“进入夜晚”或“宣布推理”作为主按钮。
2. 右侧只应有一个主流程按钮：“结束本回合，进入黄昏讨论投票”。
3. 这个按钮只有当当天必做任务完成后才能点击。
   - Day 1：必须完成 7/7 普通交谈。
   - Day 2/3/4：按当日银弹相关任务和交谈任务判断。
4. 点击后所有人聚集，开始黄昏讨论。
5. 黄昏讨论不是直接进入夜晚，NPC 需要独立讨论和表达怀疑。
6. NPC 投票应由各自模型或独立逻辑生成，像狼人杀一样有独立意识。
7. 所有 NPC 投票完成后，展示投票面板：
   - 谁投了谁。
   - 每个人获得几票。
   - 最后由玩家决定投谁。
8. 被投者发表遗言。
9. Crow 带被投者去监狱，等同死亡/出局。
10. Crow 说仪式性台词，提醒大家天黑锁门，然后进入夜晚。

### 1.7 后续天数核心任务

Day 2：

1. 如果第二天尸体仍是野兽撕咬，Crow 判定凶手是狼人。
2. Crow 当天只能做一件关键任务。
3. 可做任务包括：
   - 去五金店向老板购买制作银质子弹的工具。
   - 或找拥有银饰的女性 NPC 说服其交出银饰。
4. 如果相关 NPC 是狼人，可能拒绝、撒谎、说物品丢了或被拿走。
5. 狼人也可能提前干扰，例如买走工具、借走银饰。
6. 这些干扰必须留下线索，五金店老板或饰品拥有者知道是谁拿走的。

Day 3：

1. 如果 Day 2 已取得一项材料，Day 3 任务只剩另一项。
2. 仍有每日与所有 NPC 对话任务。

Day 4：

1. Crow 可以制造一颗银质子弹。
2. 玩家可以选择一个怀疑对象射杀。
3. 子弹最多杀死一个狼人。
4. 如果杀死一个狼人后还有另一个狼人存活，局势基本偏向好人失败。

隐藏银刀：

1. 好人阵营中有一个 NPC 拥有银质小刀。
2. 只有持刀者自己知道。
3. 持刀者夜晚可选择杀一人。
4. 杀到狼人或普通 NPC 都会杀死目标。
5. 狼人如果推理出持刀者，可提前杀死他。

### 1.8 右侧 UI 布局

1. 所有 NPC 在右侧列表中。
2. 每个 NPC 卡片应有：
   - 记录按钮。
   - 灯泡按钮/图标：有线索时亮。
   - 交谈按钮：未普通交谈时显示。
   - 深挖按钮：仅普通交谈后且有剩余深挖次数时显示。
3. NPC 卡片中不应滚动刷新大段文字，避免抖动和信息噪声。
4. 警长任务清单放在右下角，而不是夹在列表中间。
5. 右下角显示剩余深挖次数。
6. 鼠标悬浮 NPC 卡片时不应闪烁；只有点击后才进入选中状态。

## 3. 修复计划

### Phase 1：开局流程精确化

目标：把 Day 1 开局改成用户描述的完整仪式化流程。

1. 新增开局状态子阶段：
   - `body_discovered`
   - `crow_intro`
   - `round_one_alibis`
   - `crow_release`
   - `round_two_departures`
   - `day_free_roam`
2. 将 Crow 开场文本拆成多段气泡队列，而不是一句 `_case_intro_text()`。
3. 第一轮只让 NPC 回答昨晚行踪和异常，不能离开。
4. 第一轮结束后插入 Crow release 文本，再进入第二轮。
5. 第二轮 NPC 离开时强制校验：
   - 目的地有效。
   - 具体物件存在或有 fallback 物件。
   - 可达路径存在。
   - 如果路径失败，不允许标记为已离开，必须重试或选择地点可达 fallback。
6. 为“最后几个 NPC 不动”加测试：第二轮结束后所有非 Crow 存活 NPC 都应有有效 target 或已到达有效地点。

### Phase 2：右侧 UI 重新布局与任务 gating

目标：右侧 UI 按规则显示，不能再只是表面隐藏旧按钮。

1. 将 `#side-panel` 分成：
   - 顶部时间/导演摘要。
   - 中部可滚动 NPC 列表。
   - 底部固定任务区。
   - 底部主流程按钮。
2. 任务区固定在右下角，不被 NPC 列表挤走。
3. 主按钮启用条件来自后端 `can_start_dusk_discussion`，不是前端猜测。
4. 后端 `start_dusk_discussion()` 也检查当天任务是否完成。
5. Day 1 gating：`daily_interview_count >= daily_interview_total`。
6. NPC 卡片渲染改为稳定 DOM 更新，不每帧清空重建整个列表。
7. hover 样式改为轻微背景变化，不改变边框宽度；选中状态只由点击触发。

### Phase 3：交谈/深挖交互重做

目标：普通交谈和深挖符合用户描述。

1. 普通交谈按钮显示规则：
   - 未交谈：显示“交谈”。
   - 已交谈：隐藏“交谈”。
2. 深挖按钮显示规则：
   - 未普通交谈：隐藏。
   - 已普通交谈且 `deep_dive_remaining > 0`：显示“深入挖掘”。
   - 深挖次数用完：隐藏或禁用。
3. 普通交谈流程：
   - 点击按钮。
   - Crow 自动走到 NPC 面前。
   - 到达后 NPC 先主动发言。
   - 本次普通交谈计数 +1。
4. 深挖流程：
   - 点击“深入挖掘”。
   - 弹出大文本框。
   - 玩家输入问题。
   - Crow 走到 NPC 面前并先说问题。
   - NPC 回答。
   - 深挖次数 -1。

### Phase 4：黄昏讨论、投票、监狱

目标：完成从白天到夜晚的玩法闭环。

1. `start_dusk_discussion()` 将所有人聚到尸体/广场附近。
2. NPC 依次或并行生成讨论发言。
3. 每个 NPC 独立生成投票对象和理由。
4. 狼人知道同伴，投票时可掩护或嫁祸。
5. 好人不知道隐藏身份，只能基于记忆、线索、发言判断。
6. 展示投票汇总面板。
7. 玩家最终选择关押对象。
8. 被关押者遗言。
9. Crow 带人进入监狱牢房；该角色出局，不能动。
10. Crow 说夜晚仪式台词，进入夜晚。

### Phase 5：Day 2-4 银弹与银刀玩法

目标：落地用户提出的主要游戏性系统。

1. Day 2 后发现连续野兽伤痕，Crow 判定狼人可能性。
2. 引入任务状态：
   - `silver_tool_acquired`
   - `silver_item_acquired`
   - `silver_bullet_ready`
3. 每天只允许 Crow 完成一个关键任务。
4. 支持狼人干扰工具/银饰获取，并生成可追查线索。
5. 随机分配一个好人 NPC 持银刀，Crow 不可持有。
6. 夜晚银刀持有者可选择杀一人。
7. 银刀/狼人信息严格隔离。

## 4. 当前优先级

1. 先修 Phase 1 和 Phase 2，因为它们直接影响开局是否能跑通、右侧按钮是否能按规则工作。
2. 再修 Phase 3，因为交谈/深挖是 Day 1 任务 gating 的前提。
3. 最后实现 Phase 4/5，形成完整狼人杀玩法闭环。

## 5. 下一步验收标准

完成 Phase 1-3 后，至少要满足：

1. 开局 Crow 至少分 3 个气泡说明案情和玩家规则。
2. 第一轮结束后 Crow 明确放人并说明黄昏再集合。
3. 第二轮结束后，7 个 NPC 都离开聚集圈并移动到有效地点/物件前。
4. 右下角固定显示任务：`与居民交谈 0/7`。
5. 未完成 7/7 时，黄昏按钮禁用。
6. 完成 7/7 后，黄昏按钮启用。
7. 未交谈 NPC 只显示“交谈”。
8. 已交谈 NPC 才显示“深入挖掘”。
9. 鼠标悬浮 NPC 卡片不闪烁。
10. 全量测试通过，并用内置浏览器验证右侧 UI。
