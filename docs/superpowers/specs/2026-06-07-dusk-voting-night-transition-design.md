# 黄昏投票与夜晚过场玩法规格

更新时间：2026-06-07

## 1. 目标

把每天结束后的流程做成清晰、可观看、可参与的闭环：

```text
进入黄昏 -> 全员回广场 -> 固定知识揭露 -> 顺时针讨论
-> 玩家控制克罗最后发言 -> 30 秒投票 -> 最高票自动拘留
-> 克罗押送并回房 -> 夜晚不可操作过场 -> 天亮
```

本规格是黄昏投票与夜晚过场的玩法事实来源。实现和测试均以本文为准。

## 2. 黄昏视觉与集合

1. 玩家完成当天必要任务后，点击“结束本回合，进入黄昏讨论”。
2. 场景立即进入黄昏视觉状态：整体压暗，但角色、气泡和 UI 仍清晰可读。
3. 克罗用一个白色气泡说：“黄昏到了，大家一起到广场集合。”
4. 所有存活且未被拘留的 NPC 与克罗回到早晨集合使用的广场环形站位。
5. 集合完成前禁止讨论、投票和玩家自由操作。

## 3. 第一天专属狼人知识揭露

1. 该事件只在第一天黄昏触发一次。
2. 发言者固定从林梅与克劳斯中选择一名当前存活且未被拘留者。
3. 即使两人都是狼人，也必须由其中一人发言；狼人可以伪装成好人提供真实信息。
4. 默认优先林梅；林梅不可发言时使用克劳斯；两人都不可发言时，由其他存活未拘留 NPC 代替。
5. 发言由程序写死，不调用大模型。
6. 一个气泡能够完整表达时，不拆成多个气泡。只有超过可读上限时才按完整句拆分。

固定发言：

> 我今天在大学里查了不少旧资料，也专门对照了第一天死者身上的伤痕。现在我基本可以确定，那种咬痕和抓痕不是普通野兽留下的，而是狼人造成的。从伤口的形状来看，凶手很可能不止一个，甚至可能有两个。狼人是一种古老又危险的生物，白天看起来和正常人一样，也没有可怕的攻击力，是最容易被制服的时候；可一到晚上，它就会变成狼首怪物，力量和攻击性都非常强，手无寸铁的人很容易被它咬死或者抓死。所以今晚大家一定要小心，尽量待在室内。

## 4. 讨论顺序

1. 知识揭露结束后，克罗使用程序固定发言引导讨论。
2. 克罗固定发言应尽量使用一个气泡：

> 既然这样，大家就按顺序说说今天的观察，各自证明一下自己为什么不是狼人。你怀疑谁、看见了什么异常，也都可以说出来。等一圈发言结束后我们进行投票；怀疑谁就投谁，不确定也可以弃票，得票最高的人我会先暂时关进牢房。

3. NPC 从克罗左手边开始，按广场环形站位顺时针逐个发言。
4. NPC 黄昏发言由大模型生成，应结合该 NPC 的记忆、白天经历、观察、怀疑和阵营目标。
5. NPC 发言可以怀疑别人、为自己辩护、提供线索或撒谎，但此时不能直接投票。
6. 克罗最后一个发言。轮到克罗时弹出输入框，由玩家输入并发送。
7. 玩家发送后，克罗在场景中以白色气泡说出玩家输入的内容。
8. 克罗随后程序化说：“现在开始投票。”

## 5. 投票规则

1. 投票倒计时为 30 秒。
2. 所有存活且未被拘留的参与者均可投票，包括克罗。
3. 允许投自己。
4. NPC 可以投任意存活且未被拘留的参与者，也可以弃票。
5. NPC 依据自己的记忆、讨论内容、白天经历、怀疑和阵营目标独立决定，不必服从克罗。
6. 玩家只控制克罗的一票，没有越过投票结果任意指定拘留对象的权力。
7. 玩家投票后，所有投票按钮立即消失，进入等待其他人完成投票的结果展示态。
8. 倒计时结束时，未完成投票的 NPC 使用保底逻辑完成投票；玩家未投则视为克罗弃票。

## 6. 投票 UI

投票面板按当前存活且未被拘留的参与者逐行显示：

- 角色正面头像。
- 角色名字。
- 投票阶段的“投票”按钮。
- 结果阶段的整数票数。
- 投给该角色的所有投票者头像 icon。

投票结束后：

1. 得票最高者整行高亮，并显示明确标记。
2. 票数始终显示整数，不在 UI 中显示“1.5 票”。
3. 若最高票平票，警长所投对象在平票者中胜出。
4. 若警长未投给任何平票者，则使用稳定顺序选出胜者，避免流程卡住。
5. 结果区说明：“最高票平票，按警长裁决权，由警长所投对象胜出。”
6. 玩家只能确认结果，不能更改拘留目标。

## 7. 拘留与入夜

1. 玩家确认投票结果后，克罗用程序固定白色气泡说：

> {名字}得票最高，我先把他带到牢房。马上天黑了，请大家尽量待在室内，不要外出。

2. 克罗带领最高票者前往空闲牢房。
3. 被拘留者进入等价出局状态：不能移动、交谈、投票或参加夜间行动。
4. 押送完成后，克罗回到警长办公室。
5. 克罗到达警长办公室后才正式进入夜晚。

## 8. 夜晚不可操作过场

1. 夜晚场景进一步压暗。
2. 玩家不能操作地图、角色、对话或其他玩法 UI。
3. 屏幕显示夜晚过场面板，只提供进度信息，不泄露行动目标和结果。
4. 面板显示三个匿名执行者图标：
   - 两个相同的狼头图标。
   - 一个银质小刀图标或匿名村民图标，不能暴露持刀村民身份。
5. 夜晚内部顺序固定：
   - 狼人阶段先执行，目标由狼人逻辑决定。
   - 狼人阶段结束并回撤后，持刀村民阶段再执行。
6. 两个阶段各以约 60 秒为视觉预算；实现可在调试配置中缩短，但顺序不能改变。
7. 玩家只能看到进度条和阶段文字，看不到角色去向、目标、袭击过程或结果。
8. 全部夜间行动结束后，面板显示“夜晚结束”与确认按钮。
9. 玩家确认后天亮，进入第二天尸体发现与广场集合流程。第二天后续讨论另行设计。

## 9. 资源规则

1. 狼头图标使用两个完全相同的通用狼头资源，不能使用具体 NPC 头像。
2. 持刀方使用银质小刀或匿名人物资源，不能暴露具体村民身份。
3. 资源必须允许项目内使用并保存来源记录；在资源未确定前，先使用项目内可控的简洁占位图标实现功能。
4. 已确认可选的 CC0 / 公共领域资源：
   - 狼头：`https://commons.wikimedia.org/wiki/File:Wolf_Icon.svg`
   - 银刀：`https://commons.wikimedia.org/wiki/File:Knife.svg`

## 10. 验收标准

1. 第一天黄昏必定出现一次固定狼人知识揭露，发言者阵营不影响触发。
2. 长固定台词优先显示在一个白色气泡中，不机械拆成多个短气泡。
3. 所有人回到广场后才开始发言，并按顺时针顺序进行，克罗最后发言。
4. 玩家发出克罗发言后才进入投票。
5. 玩家与 NPC 都可投自己，NPC 可弃票。
6. 玩家只能控制克罗票，最高票自动拘留。
7. 平票由警长票裁决。
8. 结果面板显示整数票数与投票者头像，并明确高亮拘留对象。
9. 拘留目标被押送后，克罗回到办公室，再进入夜晚。
10. 夜晚玩家不可操作，只能看到匿名图标、顺序阶段和进度条。
